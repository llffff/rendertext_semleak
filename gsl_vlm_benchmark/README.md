# Compare VLMs as GSL scorers

This benchmark scores the 1,440 TSL60 images generated by `flux_2_dev`, `qwen_image`, `z_image_turbo`, and `longcat`. Each VLM answers two questions about an OCR-masked image. Their mean is the GSL score. Run the commands below from the repository root.

## Prepare images

Install the full scorer and download the four image sets, requests, and human labels from the [dataset](https://huggingface.co/datasets/feifeili00/rendertext_semleak):

```bash
python -m pip install ./rtsl-scorer/core ./rtsl-scorer tqdm matplotlib
python -m pip install -U huggingface_hub
hf download feifeili00/rendertext_semleak --repo-type dataset \
  --include "data/**" --include "labels.csv" \
  --include "images/flux_2_dev/**" --include "images/qwen_image/**" \
  --include "images/z_image_turbo/**" --include "images/longcat/**" \
  --local-dir .
python -m gsl_vlm_benchmark.prepare_masks --dataset .
MASKS=outputs/gsl_vlm_benchmark/masked_log
```

Mask preparation saves `manifest.csv`, one OCR record per image, and the masked images under `$MASKS`. Re-running it reuses completed masks. The full scorer includes CPU OCR; a GPU is only needed for local VLM inference.

## Run a VLM

Copy `.env.example` to `.env` and set the corresponding API key to use an online model:

```bash
# OPENROUTER_API_KEY
./gsl_vlm_benchmark/scripts/openrouter_qwen3_vl_32b.sh "$MASKS"
./gsl_vlm_benchmark/scripts/openrouter_qwen3_7_flash.sh "$MASKS"
./gsl_vlm_benchmark/scripts/openrouter_mimo_v2_6_flash.sh "$MASKS"

# DEEPSEEK_API_KEY
./gsl_vlm_benchmark/scripts/deepseek_official_v4_1_flash.sh "$MASKS"

# MULEROUTER_API_KEY
./gsl_vlm_benchmark/scripts/mulerouter_qwen3_omni_flash.sh "$MASKS"
```

For a local model, install the [Qwen VQA environment](../backends/README-vqa.md). Each local script has `start`, `eval`, and `stop` commands. Activate `qwen35-vllm` and start vLLM in one terminal, then evaluate and stop it from another:

```bash
conda activate qwen35-vllm
./gsl_vlm_benchmark/scripts/local_qwen3_vl_32b.sh start
# In another terminal:
conda activate rtsl
./gsl_vlm_benchmark/scripts/local_qwen3_vl_32b.sh eval "$MASKS"
./gsl_vlm_benchmark/scripts/local_qwen3_vl_32b.sh stop
```

The same commands are available in `local_qwen3_vl_8b.sh`, `local_qwen3_5_9b.sh`, and `local_qwen3_5_27b.sh`. Each script specifies its model, GPU allocation, and port; adjust these for your machine.

## Read results

Each run writes `outputs/gsl_vlm_benchmark/runs/<backend>__<model>/gsl.csv` with `image_id,gsl_score` and `gsl.jsonl` with the two question-level answers, confidence values, scores, and rationales. `errors.jsonl` records failed queries. Re-running skips completed images.

Human labels A and B use classes 0, 1, and 2. Their soft score is $(A+B)/4$; both human and GSL scores use $>0.5$ as the leakage threshold. The comparison requires all 1,440 labeled images.
